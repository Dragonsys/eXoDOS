NAS changes for eXoDOS v6.04
nas.patch holds the full diff against the stock 6.04 files. To apply it, put stock copies of
"Setup eXoDOS.bat", install.bat and update.bat in one folder and run:
	git apply --ignore-whitespace nas.patch

Where the stock files come from:
	Setup eXoDOS.bat	root of the eXoDOS pack
	install.bat		eXo\util\util.zip
	update.bat		Update\ inside EXTDOS.zip, which is inside eXo\util\util.zip

Setup eXoDOS.bat
	Top of file (before: set cnt=0)
		Count all game zips. 7000 or fewer means eXoDOS Lite.
		Save the NAS install.bat and update.bat to eXo\NAS, because Setup re-extracts the stock files.
	:aspectY and :aspectN
		goto ini becomes goto nas
	New sections before :ini
		:nas	offer the network share on Lite only
		:nasY	write eXo\util\nas.conf and restore the NAS scripts from eXo\NAS
		:nasN	remove nas.conf and keep the stock scripts

eXo/util/install.bat
	After: set RESTORE=NO
		set nasconf=.\util\nas.conf
	After: IF EXIST "eXoDOS\%GameName%.zip" goto next
		IF EXIST %nasconf% goto nasprompt
	After the torrent move commands
		New :extract label, shared by the torrent and NAS paths.
		The media unzip now runs only when the game has a media zip.
	:delete
		IF EXIST %nasconf% goto rmzip
	New sections before :inprogress
		:nasprompt, :nas, :nasmissing, :rmzip, :rmzipY

eXo/Update/update.bat
	Top of file
		set nasconf=..\util\nas.conf and set nas=false
	After: set filename=
		Read the share path from nas.conf.
	After the version compare
		Never offer a version older than the one installed. This applies with or without NAS.
	:updatenow
		Each aria2c line becomes: call :getupdate
		Stop at :updatefailed if the update file did not arrive, before the version is recorded.
	New sections before :exit
		:getupdate	copy the file from the share if it is there, otherwise download it
		:updatefailed	report the failure and leave the install unchanged
